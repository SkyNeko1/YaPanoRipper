## ⬡ Что это

**YaPanoRipper** — инструмент для скачивания панорам Яндекс.Карт в оригинальном разрешении. Поддерживает уличные панорамы и аэрофотосъёмку. Склеивает изображение из тайлов и сохраняет результат в JPEG или PNG.

```
19712 × 9856 px  ·  HI-RES
```

### → **[yap.skyne.ru](https://yap.skyne.ru)** ←

## 🖥 Десктоп-версия для Windows

Нативное приложение на Tauri (Rust) с автоматической ротацией User-Agent для обхода anti-bot ограничений.

**Скачать актуальную версию:**

- 📦 **[Релизы YaPanoRipper](https://github.com/SkyNeko1/YaPanoRipper/releases)** — установщик и портативная версия для Windows

> ⚠️ **Автообновление пока не реализовано.** Чтобы получить новую версию — скачай заново из релизов.

Исходники десктоп-версии лежат в `windows/`.

## ✦ Возможности

- 🛰 **Аэропанорамы** — по OID или прямой ссылке *(эксклюзив)*
- 🚗 **Уличные панорамы** — по координатам или ссылке
- 🗺 **Интерактивная карта** — Карты Яндекса
- 📐 **Выбор качества** — HI-RES / HIGH / MEDIUM / LOW
- 💾 **Экспорт** — JPEG по умолчанию, PNG по выбору
- 📍 **EXIF GPS** — координаты панорамы в JPEG, если они доступны
- 🖼 **Превью** — полная панорама перед скачиванием
- 📋 **Вставка из буфера** — кнопка для быстрого paste OID / URL

---

## ◈ Как пользоваться

**По координатам** — кликни на карту или введи широту/долготу вручную.

**По OID аэропанорамы** — вставь OID из URL Яндекс.Карт.

**По ссылке** — вставь любую ссылку Яндекс.Карт с открытой панорамой. Тип и параметры определяются автоматически.

---

## ◈ Качество

| Качество | Пример разрешения |
|----------|-------------------|
| HI-RES   | 19712 × 9856 px   |
| HIGH     | 7168 × 3584 px    |
| MEDIUM   | 3584 × 1792 px    |
| LOW      | 1792 × 896 px     |

*Реальные размеры зависят от конкретной панорамы*
